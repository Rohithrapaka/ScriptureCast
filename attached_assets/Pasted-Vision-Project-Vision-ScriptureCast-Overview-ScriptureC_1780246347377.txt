# Project Vision: ScriptureCast

## Overview

ScriptureCast is a modern, browser-based scripture presentation platform designed specifically for churches and Christian ministries.

The goal is to replace traditional desktop-based scripture projection software with a lightweight, real-time web application that displays Telugu Bible verses beautifully during worship services, sermons, and livestreams.

The system must be fast, reliable, easy to use, visually appealing, and optimized for OBS livestream workflows.

The entire application will run in a browser and consist of two synchronized interfaces:

1. Admin Dashboard (Control Panel)
2. Display Screen (Presentation View)

Changes made in the Admin Dashboard must instantly appear on the Display Screen without requiring page refreshes.

---

## Core Problem

Current church livestream workflows often require multiple applications such as OBS, scripture projection software, PowerPoint, and media tools running simultaneously.

This creates several issues:

* High resource usage
* Application crashes
* Complex volunteer workflows
* Delayed verse switching
* Difficult presentation management

ScriptureCast aims to solve this by providing a single web-based platform for scripture presentation.
